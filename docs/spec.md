# Who is this for and what's the core use?
Target audience towards people with an interest in background environmental music playing while they're doing something, either walking, working, sleeping. 

# MVP
Dashboard is done, Spotify API connected, minimum features needed for model in backend to run an analysis and give a recommendation. 

# What does the device send and what does the backend send back?
Device is going to send information such as motion, weather (API), Step cadence, Location (GPS), Sound level. Backend will send back the recommended song and start playing it through phone speaker or bluetooth device. 

# Privacy rule for camera frames
Currently camera frame capture is only a feature that will be implemented on the hardware side, the application might receive the option to be able to capture pictures at the will of the user.
